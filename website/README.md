# PAIN website

Статический сайт без сборки и внешних UI-библиотек.

- `index.html` — интерактивный обзор настоящего плеера, Smart DJ, привычки слушателя, звук, караоке, сценарии и загрузки.
- `inside.html` — устройство Smart DJ, статистика, данные и история изменений.
- `guide.html` — установка, библиотека, Wi-Fi, звук, тексты, настройки комфорта, сохранённые вайбы и закладки внутри треков.
- `styles.css` — базовые компоненты и подробные страницы; `edition.css` — продуктовая композиция, общая типографика и адаптивность. Шрифт Geist хранится локально.
- `experience.js` — доступные с клавиатуры объяснения Smart DJ и раскрытие метрик.
- `DESIGN.md` — разбор публичных страниц Apple и Spotify, принятые решения и ограничения исследования.
- `app.js` — галерея, увеличение скриншотов, меню и выбор платформы.
- `motion.js` — появления, смена скриншотов и управление движением. Декоративная волна приостанавливается вне экрана и в скрытой вкладке; пауза сохраняется локально. Сцена плеера использует CSS scroll timeline с обычным статичным представлением в браузерах без поддержки.
- `assets/logo-dark.png` / `logo-white.png` — исходный асимметричный знак PAIN. Симметричный `maple.svg` не используется на сайте.

Локальный просмотр из этой папки:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте http://localhost:4173. Все страницы и основные ссылки доступны без JavaScript. Главная уточняет последний полный релиз через публичный GitHub API. При отсутствии сети или лимите API остаются проверенные ссылки версии 1.9.2. Контрольные суммы берутся из метаданных релиза; сайт не имитирует запуск тестов или оценку качества рекомендаций.

Основной сайт — https://pain-player.vercel.app/, проект Vercel `pain-player`. Папка `.vercel/` не входит в Git. Перед публикацией проверьте связь проекта через `vercel project inspect pain-player`; развёртывание — `vercel --prod` из этой папки. Старый проект `website` и адрес painaudio — прежняя копия: не публикуйте основной сайт туда по ошибке. Пользовательские данные приложения сайту не нужны.

`analytics.js` подключает Vercel Web Analytics только на публичном сайте; в плеере этого скрипта нет. На проекте должна быть включена Web Analytics. Передаются обычные просмотры страниц, без событий поиска музыки и истории прослушивания. Главная содержит компактный раздел с примерами нового поиска; существующие скриншоты и оформление сохранены.

Canonical, Open Graph, robots.txt и sitemap.xml указывают на основной адрес. HTML-тег `google-site-verification` подтверждает владение в Search Console — сохраняйте его при изменении главной.

Проверены страницы на ширинах 320, 390, 768 и 1440 px, переключение галереи клавиатурой, увеличение/Escape, мобильное меню, глубокие ссылки установки и недоступность GitHub API. Анимации учитывают `prefers-reduced-motion`.

Скриншоты `assets/screenshots/tour-*.png` сняты с настоящего фронтенда ПК на изолированном статическом сервере. Скриншоты 1.9.0 сделаны с изолированным настоящим backend приложения; история демонстрационная, музыка синтетическая. Метаданные и локальные обложки скопированы из фонотеки только для иллюстрации интерфейса; исходная история не менялась. На сайте примеры явно подписаны. Android-скриншоты обновлены в эмуляторе из release-сборки 1.9.0 на демонстрационной библиотеке.
