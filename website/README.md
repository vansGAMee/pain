# PAIN website

Статический сайт без сборки и внешних UI-библиотек.

- `index.html` — интерактивный обзор настоящего плеера, Smart DJ, привычки слушателя, звук, караоке, сценарии и загрузки.
- `inside.html` — устройство Smart DJ, статистика, данные и история изменений.
- `guide.html` — установка, библиотека, Wi-Fi, звук, тексты, настройки комфорта, сохранённые вайбы и закладки внутри треков.
- `styles.css` — базовые компоненты и подробные страницы; `edition.css` — продуктовая композиция, общая типографика и адаптивность. Шрифт Geist хранится локально.
- `experience.js` — доступные с клавиатуры объяснения Smart DJ и раскрытие метрик.
- `DESIGN.md` — разбор публичных страниц Apple и Spotify, принятые решения и ограничения исследования.
- `app.js` — галерея, увеличение скриншотов, меню и выбор платформы.
- `motion.js` — появления, смена скриншотов и управление движением. Декоративная волна приостанавливается вне экрана и в скрытой вкладке; пауза сохраняется локально. Сцена плеера использует CSS scroll timeline с обычным статичным представлением в браузерах без поддержки.
- `assets/logo-dark.png` / `logo-white.png` — исходный асимметричный знак PAIN. Симметричный `maple.svg` не используется на сайте.

Локальный просмотр из этой папки:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте http://localhost:4173. Все страницы и основные ссылки доступны без JavaScript. Главная уточняет последний полный релиз через публичный GitHub API. При отсутствии сети или лимите API остаются проверенные ссылки версии 1.7.1. Контрольные суммы берутся из метаданных релиза; сайт не имитирует запуск тестов или оценку качества рекомендаций.

Сайт связан с существующим проектом Vercel (`.vercel/` не входит в Git). Развёртывание: `vercel --prod` из этой папки. После публикации обновите отдельный адрес командой `vercel alias set <deployment-url> painaudio.vercel.app`: этот alias не перемещается вместе с автоматически выданным доменом проекта. Пользовательские данные приложения сайту не нужны.

Проверены страницы на ширинах 320, 390, 768 и 1440 px, переключение галереи клавиатурой, увеличение/Escape, мобильное меню, глубокие ссылки установки и недоступность GitHub API. Анимации учитывают `prefers-reduced-motion`.

Скриншоты `assets/screenshots/tour-*.png` сняты с настоящего фронтенда ПК на изолированном статическом сервере. Все API-запросы перехвачены в браузере, коллекция и история демонстрационные; пользовательский сервер, телефон и библиотека не использовались. На сайте примеры явно подписаны. Android-скриншоты сохранены из прежней версии сайта.
