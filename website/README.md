# Pain Showcase & Download Website

Тактильный промо-сайт и центр загрузки музыкального плеера **Pain**, спроектированный в соответствии со стилем мягкой керамики и архитектурного клейморфизма (`Product UI Styleguide`). Без неоновых мигалок, кислотных эффектов и кричащих элементов — спокойный, плавный и высокоточный интерфейс.

---

## Возможности сайта

- **Умный детектор ОС**: Автоматически определяет Windows, Android или Linux у посетителя и подставляет соответствующую кнопку загрузки официального релиза `v1.6.1`.
- **Реальные тесты и метрики**:
  - Интерактивная консоль с реальным списком 9 тестовых сьютов (все 221 тест пройдены на 100%).
  - Кнопка интерактивного запуска тестирования с живым прогресс-баром.
  - Показатели бенчмарков: 100 000 вариантов за 315 мс (3.15 мкс на фразу), 0 байт телеметрии в сеть, 0 мс задержка воспроизведения.
- **Интерактивный симулятор Presence Engine**: Позволяет посетителям прямо в браузере протестировать генерацию естественных фраз для домашнего экрана и проинспектировать журнал фактов (`Evidence Ledger`).
- **Превью карточки профиля**: Демонстрация функции экспорта честной статистики прослушивания.
- **Матрица загрузок с SHA-256**: Таблица всех бинарных файлов (Windows .exe, Windows .zip, Android .apk, Linux .tar.gz, Source .zip) с копированием контрольных сумм в один клик.

## Развертывание на Vercel

### Вариант 1: Через Vercel CLI (Мгновенно)
Из папки `website/`:
```bash
cd website
npx vercel --prod
```

### Вариант 2: Через GitHub репозиторий
1. Перейдите на [vercel.com/new](https://vercel.com/new).
2. Выберите ваш репозиторий `vansGAMee/pain`.
3. В поле **Root Directory** укажите `website`.
4. Нажмите **Deploy**.

---

## Локальный запуск

Для локального предпросмотра:
```bash
cd website
npm run dev
# Или:
# npx serve . -l 3000
# python3 -m http.server 3000
```
Сайт откроется по адресу `http://localhost:3000`.
