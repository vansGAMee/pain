# Проверка исправлений 1.8.7

30 октября 2026 года, отдельные временные профили. Рабочая библиотека и история не редактировались.

## Сети РФ и установка

На одних и тех же узлах Globalping в Новосибирске (МТС) и Томске выполнены HTTP-проверки конкретного файла torchvision из сообщения об ошибке:

- `download-r2.pytorch.org`: оба соединения завершились тайм-аутом, около 15 секунд.
- `download.pytorch.org`: оба узла получили HTTP 200 примерно за 0,52 секунды.
- Файл Windows torchvision скачан с альтернативного официального адреса; SHA-256 совпал с опубликованным в CPU-индексе: `ebdeb19a49da0b5d11cc512a76b24a43971e17cfb9c1ec42564d0e300670d5fa`.
- Настоящий uv выполнил dry-run установки трёх закреплённых CPU-библиотек по новым URL: зависимости разрешены. Установленный рабочий Python не менялся. Полная чистая установка 1.8.6 на Linux и Windows/Wine была проверена ранее; здесь меняются адреса доставки тех же файлов.
- Отдельные тесты проверяют оба набора платформенных файлов, совпадение хешей между официальными CDN, переключение при сетевой ошибке и отсутствие повторных попыток при повреждении файла/отмене.

[Новый адрес](https://api.globalping.io/v1/measurements/2M1TaDLnXnQx1WNDI00021PLS), [прежний адрес](https://api.globalping.io/v1/measurements/2k6M1MAHWTAeJdvBG00021PLS). Сервис хранит результаты ограниченное время. Это наблюдения в двух сетях, а не гарантия для любого российского провайдера.

## Текст

На тех же российских узлах каталог KuGou вернул SUA CAVALONA. Затем по идентификатору записи получен и скачан настоящий текст: HTTP 200, 1458 символов, 33 строки с исходными таймингами для другой скоростной версии.

Рабочий модуль на ПК с принудительно недоступным LRCLIB нашёл:

- SMOKE IT OFF! [Slowed & Reverb]: KuGou, 80 синхронизированных строк для совпавшей записи.
- SUA CAVALONA (Hardstyle Remix) (Ultra Slowed), исполнители через `/`: KuGou, 33 строки. У варианта Ultra Slowed нет текста в ответе источника; взяты слова другой скоростной версии, тайминги удалены и показана соответствующая пометка.

Проверены пустой поиск по словам с последующим поиском по каталогу/хешу, составные обозначения изданий, отклонение другого ремикса и исполнителя, отсутствие ложного суточного кэша при сетевой ошибке, отмена запроса старого трека при переключении.

## Переключение

Копия реальной фонотеки: 773 трека, настоящие локальные MP3, история из сохранённого снимка. CPU замедлен через CDP в шесть раз. Проверены переходы, отсутствие ошибок страницы и сохранность акустического кэша после отложенной записи. Проверки Web Audio отдельно подтверждают слышимый выход, паузу/возобновление, восстановление после приостановки контекста и временной ошибки источника.

Профилирование показало повторные обновления DOM и синхронное сохранение акустического кэша. Обновления строк объединены в один кадр; сохранение откладывается на свободное время вне перехода. Фоновый анализ получает пониженный приоритет и один поток. Это не замер на самом компьютере друга: драйвер, диск и доступность телефона этой проверкой не воспроизводятся, отдельные задержки интерфейса остаются.

533 Node-теста пройдены. В том числе настоящий дочерний процесс проверяет снижение приоритета, а измерение звука проверяет пропуск кадров анализа на время перехода без засчитывания паузы в данные.
