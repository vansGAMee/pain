# Проверка 1.8.8

30 октября 2026 года. Временные профили и HTTP-фикстуры; личная библиотека и история не редактировались.

## Поиск текста

Рабочий модуль, настоящие ответы источников:

- `Rammstein — Angel (eng)`, 264 секунды: LRCLIB вернул немецкие слова для записей `Angel`. Определитель franc отнёс их к немецкому; они отклонены. KuGou вернул английский текст: 27 строк с таймингами, язык `eng`.
- `Rammstein — Engel`, 264 секунды: LRCLIB, 36 строк, язык текста `deu`.

Использован опубликованный [franc](https://github.com/wooorm/franc/tree/5.0.0), компактная модель, стандартные настройки. Это статистическая проверка текста, не распознавание языка аудио; короткий или смешанный текст может быть отклонён. Коды и названия языков — ISO/Intl, без таблицы конкретных песен. Сравнение названий сохраняет отличия языковой версии, ремикса и live. Для совместимости старого Windows EXE используется CommonJS-версия, зависимость trim закреплена на исправленном 1.0.1.

Регрессии проверяют: одинаковые название/длительность с неверными словами; отдельную проверку обычного и синхронного текста; корректную нормализацию языковых пометок; отсутствие подстановки другого языка, исполнителя или произведения; перепроверку старого автоматического кэша без изменения ручных правок.

## Запуск треков

Браузер запускает настоящий сервер приложения и отдельный HTTP-сервер телефона. Телефон отвечает 404 на сохранённый ID и выдаёт ту же запись под новым ID. В качестве аудио передаётся настоящий WAV; Web Audio измеряет ненулевой выход после декодирования.

- С сервером из тега `v1.8.7` воспроизведён отказ запуска.
- Исправленный сервер восстановил запись, сохранив прежний ID и байты JSON библиотеки.
- Через интерфейс проверены видимое ожидание, отмена, возобновление и понятная ошибка отсутствующего файла. При окончательном отказе исходящая дека останавливается.
- HTTP-тесты проверяют сохранение Range/HEAD, отсутствие кэша частичного ответа, атомарную замену повреждённого кэша, отмену передачи и отклонение неоднозначных совпадений.
- Дополнительно пройдены браузерные проверки плавных переходов, быстрого переключения при медленной загрузке, паузы/возобновления, приостановленного AudioContext и повторной попытки после временной ошибки.

540 Node-тестов пройдены. Это воспроизведение конкретных сценариев, а не проверка физического компьютера друга или гарантия отсутствия всех задержек на слабом оборудовании.
