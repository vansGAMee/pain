- ПК: поиск караоке различает языковые версии. Пометки `eng`, `English Version`, `- English` и названия других поддерживаемых языков приводятся к общему виду; проверяется язык самих слов. Немецкий текст больше не принимается для явно английской версии, даже если название и длительность совпадают.
- ПК: запасной поиск умеет найти текст, когда источник пропустил языковую пометку. Другой исполнитель, ремикс или концертная запись не подставляются. Тайминги принимаются только при совпадении версии и длительности.
- ПК: исправлен запуск после смены Android ID файла. Плеер восстанавливает доступ только при единственном совпадении названия, исполнителя, длительности и размера. Учитывается запись исполнителя в имени файла; ID библиотеки, лайки и история сохраняются.
- ПК: во время загрузки виден индикатор; кнопка отменяет ожидание. Ошибки подключения, отсутствующего или недоступного файла объясняются в интерфейсе. Повторная попытка проходит через тот же механизм восстановления; испорченный кэш заменяется только после полного скачивания.

Проверены оба трека из примера: `Angel (eng)` — английские слова из KuGou, `Engel` — немецкие из LRCLIB. Конкретный источник может быть недоступен или содержать ошибочные данные: приложение не обещает текст каждой записи и не подменяет его другой версией ради результата. Ручные тексты остаются приоритетными.

Windows: `Pain-v1.8.8-Setup.exe` или `Pain-v1.8.8-Windows.zip`. Linux: `Pain-v1.8.8-Linux.AppImage`. Прежние форматы `Pain-v1.8.8.exe` и `Pain-v1.8.8-Linux.tar.gz` сохранены для совместимости; Linux-архиву нужен Node.js 18+. Контрольные суммы: `SHA256SUMS-v1.8.8.txt`.

Android APK имеет прежнюю подпись и общий номер версии. Перечисленные исправления относятся к ПК. Windows-сборки без Authenticode-подписи.
