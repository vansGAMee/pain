# PAIN 1.9.4 — Companion API, факты воспроизведения и умные послания на главной

Новые возможности интеграции и персонального контекста на ПК.

- **Companion Control API:** локальный API для внешних компаньонов, оверлеев и виджетов рабочего стола (`/api/companion-control/`).
- **Факты воспроизведения:** выделенный легковесный эндпоинт `/api/companion-playback` для чтения текущего трека, времени, громкости и статуса (только для локальных процессов, без прямого доступа к файловой системе).
- **Точный статус в Discord Rich Presence:** поддержка передачи уровня громкости и частоты воспроизведения в состояние Presence.
- **Умные контекстные фразы на главной:** персональные короткие сообщения (`home-messages`), подстраивающиеся под язык, время суток и темп вашей медиатеки, с гарантированным ограничением до двух строк во всех темах («Форма», «Сакура» и др.) на экранах любой ширины.
- **Синхронный комплект обновления:** Android APK (код 43), Windows Setup/ZIP, Linux AppImage и исходные тексты.
