# Проверка 1.8.6

Проверки выполнены на изолированных профилях, без остановки основного плеера.

- 524 Node-теста: установщик, подписи файлов, отмена/повтор установки, доступ только с локального адреса, рекомендации, учёт прослушиваний и остальные существующие проверки.
- Реальная установка с нуля на Linux и Windows под Wine: скачаны закреплённые uv, Python 3.11, CPU PyTorch и зависимости из requirements.lock. Пройдены проверка совместимости пакетов, импорт numpy/scipy/sklearn/faiss/torch/torchaudio/laion_clap, фактический поиск FAISS, вычисление PyTorch и запуск ffmpeg/ffprobe. Системный Python и рабочая фонотека не использовались для установки.
- Браузер: сценарий 477 недоступных файлов без Python, кнопка установки и её состояния, свёрнутый список файлов, отсутствие ENOENT в основном тексте. Настоящий WAV продолжал играть во время изменения состояния установщика.
- Упакованное Linux-приложение: старт с пустым профилем, доступная кнопка установки, сохранение режима источников текста. Windows EXE: старт под Wine, ответ нового API из отдельного профиля.
- Источники текста: отказ соединения и ограничение запросов LRCLIB не блокируют KuGou; неподходящие исполнитель/версия отклоняются; при несовпадении длительности тайминги удаляются. Проверены локальный кэш, отключение, приоритет ручных правок и смена режима после сохранённого отрицательного результата.
- Живой запрос через рабочий модуль: Radiohead — Creep найден в KuGou, 42 синхронизированные строки. Это проверка подключения, а не заявление о покрытии всех песен или доступности из каждой сети РФ.
- Android: unit-тесты и три инструментальных теста LyricsLookup на эмуляторе API 34, включая независимый резервный HTTP-источник после ошибки 503. Release APK собран, сертификат совпадает с 1.8.5.
- Воспроизведены и исправлены два сбоя воспроизведения: Play после приостановки AudioContext и повторный Play после временной ошибки медиаисточника. До исправления соответствующие браузерные проверки завершались тайм-аутом, после — проходят. Проверяется реальный выходной сигнал Web Audio, естественный переход a → b → c, повторное использование прогретого декодера, быстрые переключения, пауза/возобновление и перемотка.
- История: все 5002 прежних события и 9171 временной интервал из контрольной копии сохранены в рабочем файле; во время работы плеер добавлял новые события. Фонотека, состояние рекомендаций и исходный индекс совпадают с контрольными хешами.

Проверка Windows выполнена через Wine, а не на отдельном компьютере с Windows. Загрузка большой модели CLAP после установки зависит от сети; отдельные записи могут отсутствовать в каталогах текстов.
