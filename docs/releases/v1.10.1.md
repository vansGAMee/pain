Короткие сообщения на главной в версии для компьютера стали разнообразнее. PAIN может предложить трек со знакомого альбома, заметить песню, которая заняла больше половины сегодняшнего эфира, или напомнить о давнем избранном.

- В каталоге 54 типа наблюдений и 106 формулировок на каждом из двух языков. Для пустой фонотеки есть 12 вариантов.
- Редкие фразы появляются по событиям из истории. Среди них годовщина открытия трека, возвращение самой первой песни и первые сутки музыки.
- Сообщения подбираются на устройстве без ИИ. PAIN старается показывать новые факты раньше других формулировок и помнит недавние фразы после перезапуска.

Для обновления установите новую версию поверх текущей, чтобы сохранить фонотеку и историю.
