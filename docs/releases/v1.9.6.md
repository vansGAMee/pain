# PAIN 1.9.6 — аккуратная прокрутка фонотеки

- **Плавная полоса прокрутки.** В разделе фонотеки полоса прокрутки скрыта по умолчанию и плавно проявляется только при наведении курсора на рабочую область, а при уводе мыши плавно растворяется, сохраняя чистый визуальный стиль.
- **Чистая панель.** Боковая панель и навигационные списки остаются лаконичными без навязчивых элементов прокрутки.

Алгоритм рекомендаций не изменён. Перечисленные улучшения относятся к ПК. Android получает согласованную версию 1.9.6 (код 45) без изменения рекомендаций или интерфейса.

Сборки: Android APK, Windows Setup/ZIP, Linux AppImage и исходный код. Контрольные суммы — в `SHA256SUMS-v1.9.6.txt`.
