# Проверка 1.8.11

31 октября 2026 года. Личные JSON читались и копировались во временные профили; исходная библиотека и история не редактировались. Для передачи через VPS использованы синтетические WAV, без личной музыки.

## Рекомендации и графики

Модель Python, очередь рекомендаций, её адаптер и выбор треков не изменены. Визуальная карточка отображает поля уже записанного решения: `listens`, `completed`, `heardFraction`, `liked`, `historyEvents`, `learnedShare`, `anchors`, контекст времени/вайба. Если измерения нет, показывается прочерк. Доли двух методов не выдаются за сходство, важность отдельного признака или вероятность понравиться.

`personal-browser.cjs` прошёл с настоящими аудиофайлами и копией истории: модель использовала 5221 пригодное событие, звук играл, объяснение открылось, 512-мерный вайб сохранился и восстановился. Шесть строк главной прошли в показанном порядке; затем возобновились рекомендации. Входная копия сохранилась побайтно.

Причина исчезновения графиков: worker загружал `listening-insights.js`, который обращался к отсутствовавшему в worker модулю `ListeningRecords`. Порядок импорта исправлен. Браузерная проверка на копии реальной истории строит 20 графиков для всех трёх периодов, прокручивает каждый до фактического SVG и проверяет отсутствие NaN/Infinity. Сохранено отложенное рисование невидимых графиков.

## Совместное прослушивание

`together.test.js` запускает два настоящих HTTP-сервера приложения и отдельный relay. Проверены ведущий/предложения, запрет гостевого управления, принятие предложения, равные права, пауза/позиция, однократный следующий трек при одновременном окончании у двух участников и закрытие комнаты. Отсутствующий у гостя WAV действительно проходит через оба приложения и relay; проверены точные байты полного ответа и Range. Источники браузера не подменялись.

`together-browser.cjs` запускает два независимых браузерных контекста с разными фонотеками. Проверены реальные ненулевые выходы Web Audio у обоих, общая позиция после буферизации, пауза/перемотка/возобновление, равные права, естественное окончание и продолжение очереди, восстановление ведущего после принудительного разрыва WebSocket. Скриншоты карточки, комнаты и графиков просмотрены.

`together-tls.test.js` создаёт отдельный тестовый сертификат. При несовпадающем SHA-256 сервер не получает ни одного HTTP-запроса с ключом/путём; при правильном отпечатке запрос проходит. HTTP за пределами localhost отклоняется.

`together-stream-cancel.test.js` начинает передачу 100-МиБ потока и отменяет чтение после первой порции. Источник закрывается до отправки всего содержимого, слот освобождается. Передача использует обратное давление `pipeline`, файлы и буфер всего трека на relay отсутствуют.

## Настоящий VPS и Windows

`together-remote-audit.cjs` соединяет два сервера приложения через развёрнутый HTTPS relay. Проверены отпечаток сертификата, общая очередь, передача 99 900 байт Range с точным сравнением, общая пауза/позиция и закрытие комнаты. Контрольная передача с действиями завершилась примерно за 900 мс; скорость других соединений не обещается.

`together-windows-audit.cjs` запускает собранный Windows EXE в настоящем Windows Node runtime под Wine. Его партнёр — Linux-приложение; соединение проходит через тот же VPS по TLS. Проверены загрузка упакованного интерфейса, кириллица в метаданных, управление из Linux и передача 9800 байт музыки из Windows. Это не проверка на физическом компьютере друга.

`together-native-audit.cjs` прошёл на собранном Linux Electron: настоящий backend worker и ресурсы ASAR, создание комнаты через интерфейс, воспроизведение аудио, передача записи второму приложению и загрузка всех 20 графиков. Проверены совпадение изменённых файлов в обоих нативных пакетах с исходниками, версия ws, зависимости Linux-архива и SHA-512 обоих манифестов обновления. Подпись Android APK сохранилась.

На VPS создан только отдельный сервис `/opt/pain-listen`, контейнер `pain-listen`, TCP 8448. У него read-only файловая система, не более 128 МиБ памяти, 0.35 CPU, 64 процессов и 2 МиБ журналов. В контрольных замерах после передачи — около 13 МиБ памяти. Музыка и комнаты не записываются на диск.

VPN-контейнер `amnezia-awg2` до и после развёртывания имел тот же ID, время запуска и RestartCount=0; UDP-порт 35185 остался на месте. Настройки VPN, Docker daemon, маршруты и правила firewall не менялись. Relay использует host network и отдельный свободный TCP-порт.

555 Node-тестов пройдены. Дополнительно проверены прежние естественные плавные переходы, слышимый выход, пауза/возобновление, быстрое переключение и порядок подборки главной при доступной/недоступной модели. Android unit-тесты и release-сборка пройдены.
