# PAIN 1.9.2 "Alya"

Мгновенный переход треков на ПК, фоновый разогрев декодера и точные связи песен в инсайтах.

- Подготовка воспроизведения на ПК теперь запускает декодер следующего трека сразу в фоне, не дожидаясь завершения фонового анализа переходов.
- Потоковый ответ `/api/cached-track` используется напрямую, без отдельного предварительного запроса полной загрузки `/api/preload-track`, устраняя дублирование сетевых запросов.
- При переключении без плавного перехода (кроссфейда) неактуальный декодер выгружается, освобождая буфер и отменяя ненужную передачу данных.
- Многократные быстрые нажатия «Вперёд» (Next) во время загрузки или выбора трека теперь объединяются в один аккуратный переход, не накапливая очередь пропущенных песен.
- Импортированные локальные файлы воспроизводятся напрямую без синхронного копирования в кэш.
- График «Песни, которые встречаются» (Transitions) в инсайтах теперь исключает повторы одного и того же трека из графа переходов, сохраняя их в общем счётчике прослушиваний. Длинные названия обрезаются с многоточием и показывают полное название по наведению.
- Синхронное обновление Android APK, Windows Setup и Linux AppImage с единой версией 1.9.2.
