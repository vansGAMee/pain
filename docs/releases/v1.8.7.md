- ПК: исправлено скачивание CPU-компонентов анализа из сетей, где недоступен download-r2.pytorch.org. Используются альтернативный официальный адрес и контрольные суммы.
- ПК: улучшен поиск текста через каталог KuGou — поиск записи, её версий и текста по идентификатору аудио.
- ПК: исправлено сопоставление нескольких исполнителей и пометок Remix / Ultra Slowed. Текст другой скоростной версии показывается без неподходящих таймингов.
- ПК: поиск текущей песни больше не ждёт запросов пропущенных треков; ошибка сети не сохраняется как отсутствие текста на сутки.
- ПК: меньше повторных перерисовок при переключении, анализ ждёт воспроизведения, фоновым процессам снижен приоритет.

### Что проверено

На двух российских узлах проверены оба адреса PyTorch: прежний адрес не завершил TLS-соединение, альтернативный вернул HTTP 200. Файл torchvision для Windows скачан с альтернативного адреса и совпал с SHA-256 официального индекса. На тех же узлах KuGou ответил и нашёл запись SUA CAVALONA из присланного скрина. Это проверка конкретных сетей, а не гарантия доступности у каждого провайдера РФ.

Для SUA CAVALONA (Hardstyle Remix) (Ultra Slowed) исправленный модуль нашёл 33 строки. Синхронизированного текста именно этой версии источник не вернул: показываются слова другой скоростной версии с явной пометкой, без её таймингов.

### Установка

Windows: `Pain-v1.8.7-Setup.exe` или `Pain-v1.8.7-Windows.zip`. Linux: `Pain-v1.8.7-Linux.AppImage`. Прежние форматы `Pain-v1.8.7.exe` и `Pain-v1.8.7-Linux.tar.gz` сохранены для совместимости; Linux-архиву нужен Node.js 18+.

После обновления можно нажать **«Повторить установку»** в настройках. Системный Python не меняется. Режим источников текста «Автоматически» сохранён; для сети с недоступным LRCLIB есть «Сначала запасной». Старые неудачные поиски будут перепроверены автоматически, ручные правки сохраняются.

Android APK имеет прежнюю подпись и общий номер версии. Перечисленные исправления относятся к ПК. Контрольные суммы всех файлов: `SHA256SUMS-v1.8.7.txt`. Windows-сборки без Authenticode-подписи.
