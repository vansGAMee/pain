# PAIN 1.6.0

Комплексное обновление: календарь привычек и статистика прослушиваний, умное выравнивание громкости, надежная оффлайн-синхронизация с телефоном и улучшенная диверсификация Smart DJ.

## Ключевые изменения

1. **Детали привычек (Listening Insights)**:
   - Вкладка «Инсайты» дополнена 28-дневным календарем активности с тепловой картой интенсивности.
   - Выделение треков-ритуалов (регулярно прослушиваемых в разные дни), треков-возвращений после долгой паузы и метрика удержания открытий за месяц.
   - Подсчет только реального покрытия трека (`heard`), исключая накрутку от частых перемоток и случайных кликов.

2. **Умный уровень громкости (Smart Volume Leveler)**:
   - Медленный выравниватель (`leveler`) мягко балансирует треки с разным мастерингом после применения эквалайзера.
   - Встроенный компрессор с быстрой атакой отсекает резкие перегрузки без внесения искажений.
   - Защита от разгона гейна в тишине, паузах и на затуханиях.
   - Сохранение уровня при перемотках и приглушение при сворачивании окна в фон.

3. **Надежная синхронизация с телефоном (Offline Phone Sync)**:
   - Внедрена постоянная очередь локальных изменений (`sync-pending.json`): лайки и прослушивания на ПК не теряются без сети и отправляются при подключении телефона.
   - Автоматическое восстановление истории ПК из старых версий плеера.
   - В Android-сервере синхронизации (`SyncHttp.java`) реализован побайтовый парсер HTTP с корректным подсчетом Content-Length для UTF-8 строк с кириллицей и эмодзи.

4. **Интеллект Smart DJ и акустическая модель**:
   - Диверсификация памяти звука: алгоритм сохраняет разнородные подтвержденные предпочтения, избегая доминирования одного подстиля.
   - Учет инструментальной текстуры (`instrument-texture`) в дополнение к тембру.
   - Удержание настроения сессии по нескольким принятым трекам для плавных естественных переходов.
   - Мягкий перенос первого понравившегося звучания при холодном старте.

5. **Windows-окружение**:
   - Официальная многослойная иконка в PE-ресурсах файла `Pain.exe`, отображение значка в панели задач и меню `Alt+Tab`.
   - Графическая подсистема PE (subsystem 2) — запуск плеера без консольного окна.
