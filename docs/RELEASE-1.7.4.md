# PAIN 1.7.4 — срочное исправление запуска Windows

Исправлена ошибка, из-за которой запуск второй копии из EXE или ZIP мог открывать несколько окон. При поиске свободного порта накапливались обработчики запуска; теперь окно открывается один раз на фактическом порте, число попыток ограничено. EXE и ZIP используют общий локальный блокировщик: повторный запуск передаёт запрос существующему процессу и завершается. Частые повторные запуски ограничены, фоновая синхронизация запускается только у владельца.

Для закрепления на панели задач добавлены собственная идентичность окна PAIN, логотип в постоянной папке LocalAppData и команда повторного запуска Pain.exe вместо браузера. Создаётся ярлык PAIN в меню «Пуск». Исправлен запуск VBS из другой рабочей папки и стандартный адрес favicon.ico.

**Если окна уже размножаются:** завершите все процессы Pain/Pain-v*.exe в Диспетчере задач либо перезагрузите Windows. Старые запущенные EXE не исправляются заменой файла на диске. Замените EXE в своей постоянной папке; сохраните папки data, downloads, cache и covers. EXE и ZIP — два способа получить одну программу, устанавливать оба не нужно.

**Иконка:** открепите прежний значок один раз, запустите новую версию, подождите несколько секунд и закрепите PAIN заново. Можно закрепить ярлык PAIN из «Пуска». Не удаляйте и не переносите EXE после закрепления.

Проверки: 281 автоматический тест; настоящий собранный Windows EXE под Wine — четыре повторных запуска переименованной копии завершаются, работает один сервер, favicon и помощник оформления включены в сборку. Реальную панель задач Windows в этой среде визуально проверить нельзя. Изменения оформления используют документированный механизм [Windows AppUserModel/RelaunchIconResource](https://learn.microsoft.com/en-us/windows/win32/properties/props-system-appusermodel-relaunchiconresource).

Android включён с новым номером версии для целостного автообновления; интерфейс и библиотека на телефоне не изменены. В релизе: EXE, Windows ZIP, Linux, APK, исходники и SHA-256.
