# PAIN 1.5.2

Микро-фикс для Windows и интеграции в систему: встраивание иконки, нативное окно и скрытие черной консоли. Функционал плеера сохранен без изменений.

## Что сделано

1. **Встроенная иконка в исполняемый файл**:
   - В PE-ресурсы `Pain.exe` внедрен многослойный значок `app-icon.ico` (от 16x16 до 256x256).
   - В Проводнике, свойствах файла и на рабочем столе файл отображается с оригинальным логотипом Pain.
   - Заполнены метаданные PE (ProductName, FileDescription, CompanyName, FileVersion).

2. **Скрытие консоли**:
   - PE Subsystem пропатчен на `IMAGE_SUBSYSTEM_WINDOWS_GUI` (2).
   - Запуск `Pain.exe` больше не открывает окно `cmd.exe`.

3. **Интеграция в панель задач**:
   - Добавлен `manifest.json`, подключенный в `index.html`.
   - Сервер отдает `.webmanifest` и `.ico` с корректными заголовками.
   - Окно Microsoft Edge / Chrome в режиме `--app` и окно Electron получают иконку в панели задач и в Alt+Tab.

4. **Ярлык на рабочем столе**:
   - `Create-Desktop-Shortcut.vbs` обновлен для привязки иконки.
